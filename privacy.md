# Alfred - Privacy Policy

Last updated: October 16, 2026

Alfred is a private personal assistant operated by David Sanmartin for his own use only. It is not available to the public.

## Data accessed

With the owner's explicit authorization, Alfred accesses the owner's own Google Calendar, Gmail and Google Drive data through Google APIs.

## How data is used

Data is used only to answer the owner's requests, such as summarizing emails, checking the calendar or preparing drafts. Nothing is sent to third parties without the owner's explicit approval.

## Storage and security

Data is processed on the owner's own computer. Access tokens are stored encrypted and are never shared. Data is not sold, not used for advertising and not used to train AI models.

## Google API Services User Data Policy

Alfred's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions
